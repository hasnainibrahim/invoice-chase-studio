# Rules for the data folder

These rules apply to every file in `data/`.

- The customers here are made-up practice customers. They are not real people or companies.
- Never add a real customer or a real email address to this folder.
- Every email address must end in `.example`.
- Never change an invoice number, an invoice date or an amount. Copy them exactly from the sheet.
- When an invoice is paid, it is removed from next week's sheet. Never edit it or delete it here.
